# Asset sources

- The pixel portrait belongs to Dhruv Vasisht and is reused from his portfolio (`public/assets/logo.png`).
- Technology glyphs are reused from the portfolio's existing SVG components; the [Devicon MIT license](./DEVICON-LICENSE.txt) is included for those glyphs.
- The animated desktop and mobile headers are custom SVG artwork. They embed the existing portrait, use declarative SVG/CSS animation, and include a static presentation for reduced-motion preferences.
- The desktop and mobile GIF headers are browser renders of the editable SVG source files. Static PNG versions are selected when reduced motion is preferred. The header uses the existing portrait without modifying its identity.
- Badge backgrounds, labels, and layout were created for this README. These files have no runtime dependency on a badge or statistics service.
- Product names and logos remain the property of their respective owners.
